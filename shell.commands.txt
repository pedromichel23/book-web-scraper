scrapy shell
scrapy crawl bookspider // teniendo el archivo bookspider.py
fetch('url')
response.css('article.product_pod')
books = response.css('article.product_pod')
len(books)
book = books[0]
book.css('h3 a::text').get()

# Explicacion
h3 a → es un selector CSS estándar.
::text → es una extensión de los selectores de Scrapy.
.get() → es un método de Scrapy para obtener el primer resultado

.getall() → es un método de Scrapy para obtener todos resultados
